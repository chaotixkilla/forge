This phase turns the recruitment plan into raw material: each chosen lane's explorer runs and returns anchored findings in its own lane's shape. Your job is to run them, capture what they hand back without editing it, and know when the picture has stopped moving.

## Recruit the lanes in parallel
1. Recruit one explorer per chosen lane, in parallel via the available fan-out mechanism — or, without fan-out available, run each lane's gather yourself in sequence, following that lane's own method (its explorer agent in [agents/explorers/](../../../agents/explorers/)) before moving to the next. The `knowledge-base` lane reads through the [knowledge](../../knowledge/SKILL.md) port, which owns `tools.knowledge` and resolves the backend; neither this phase nor the lane resolves it.
2. Capture each explorer's findings verbatim, tagged with its lane and carrying its own anchors (file:line, commit/PR, page + provenance, URL + section, origin links) and its intra-lane grade. Do not weigh or edit yet — collection is neutral; weighing is phase 03.

## Chase leads to saturation
3. Harvest the leads a lane surfaces (a referenced commit, a cited spec, a named pitfall) and re-query the lane that owns them. Keep chasing across rounds until new sources stop changing the picture — the saturation test in [know-when-to-stop](../rules/know-when-to-stop.md), not "until queries run out." `--rounds=<n>` caps the rounds; `--budget=<n>`, when it binds first, stops the chase early — see [budget-discipline](../modules/budget-discipline.md).

## Handle the degraded and empty cases

Two misses read identically downstream and must not: a lane that **could not be consulted**, and one that **was consulted and found nothing**. Sort every miss by one question — **did the lane's own search actually reach the source it owns?** An absence is a claim *about the source*, earned only when the lane's method ran against that source and came back empty; anything that stopped the search short is a fact about the *run*. When you cannot tell which happened, it is **not consulted** — a spurious drop is visible and recoverable, while a fabricated absence is indistinguishable from a real one and is read downstream as established fact. `(basis: derived — the two buckets already exist as distinct slots in [04-return-the-picture](04-return-the-picture.md); what was open is which one a miss lands in. Reached-the-source is the primitive that sorts any cause — unconfigured, flag-gated, unauthenticated, a transport the caller's context cannot dial, rate-limited, backend down, or a cause not yet seen — without an enumeration that ages. The tie-break follows the asymmetry of harm, not a preference.)`

4. A lane whose search never reached its source is dropped with an explicit note — `lane X not consulted: <reason>`, the reason naming what blocked the reach — never silently skipped; the picture must show which lanes it rests on.
5. A lane whose search reached its source and came back empty returns a documented absence — `no finding in lane X; searched <where>` — which is carried forward: an absence is a result, not a gap to hide. Naming a `<where>` does not establish reach: a lane that could not dial its backend can still return a well-formed absence naming the source it never queried. Where the return does not establish that the search executed against the named source, the tie-break above fires and the miss belongs in step 4 ([separate-provenance-from-conclusion](../rules/separate-provenance-from-conclusion.md) — the run's own failure must never inherit the authority of the source's silence).

The output of this phase: the pooled, lane-tagged, anchored findings — every consulted lane represented by findings or a documented absence, ready to weigh.
