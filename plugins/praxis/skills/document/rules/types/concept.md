# Concept

How an outside standard or framework maps onto this system's implementation.

## Membership

A result that relates something defined outside the project — a standard, a protocol, a framework's model — to how this system implements it, naming where they match and where the system departs, each with its source on both sides.

System documentation says how one part of the system works now. It covers only what the task touched, is dated by the task, and is never edited after the task ends: a later task writes its own pages and links back. A page covers one part and one content type — no whole-system overviews — and every claim cites its source: code, documentation, a test result, a conversation. (basis: maintainer, 2026-09-30, after Diátaxis)
