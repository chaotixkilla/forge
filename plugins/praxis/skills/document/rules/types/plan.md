# Plan

The design a task builds against: the chosen approach and the alternatives it was weighed against, the interfaces and boundaries it draws, the hard parts, how it rolls out, and the slices it ships in.

## Membership

The plan step's result. Each choice the plan makes that would be costly to reverse also files as its own [decision record](decision-record.md), which the plan links rather than repeats. (basis: maintainer, 2026-09-30)
