# Audit report

A security audit's account of a system's posture, for the system's owners.

## Membership

The security-review step's result in an auditing task, led by the posture line and the verdict line as the review gives them, then the scope, then the findings, then the rest in the review's order ([reporting-findings](../../../security-review/phases/05-reporting-findings.md)). The message the act sends the owners links the report rather than restating it. (basis: derived from the deliverable of the act that files it; maintainer, 2026-10-02, for the order)
