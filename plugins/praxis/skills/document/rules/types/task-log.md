# Task log

One flat page with one line per task, newest update first, for people who don't use praxis. It mirrors the task memory entries and holds nothing they don't.

## The line

`<date updated> · <key> — <title> · <status> · next: <next step> · <link to the task record>`

For example: `2026-10-02 · review-230 — review the invoice export change · open, delivery pending · next: post the review on review request 230 · task record`.

No index and no categories, now or later: the page's only order is by date. (basis: maintainer, 2026-09-30.)
