# Spike findings

What a prototyping task learned. The code it built is thrown away; the findings are what it was for.

## Membership

The prototype step's result: the question it set out to answer, what was built to answer it, the observed result read as answered, refuted or still open, and the learnings a later spec or plan should take, each with the observation behind it. (basis: derived from the deliverable of the act that files it)
