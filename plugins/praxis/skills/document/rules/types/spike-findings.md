# Spike findings

What a prototyping task learned. The code it built is thrown away; the findings are what it was for.

## Membership

The prototype step's result, led by its result on the assumption the question set out to test — `holds`, `fails`, `unsettled` or `not checked` with its reason ([results-and-certainty](../../../../craft/evidence/results-and-certainty.md)) — then the observation the result rests on, what was built to get it, and the learnings a later spec or plan should take, each with the observation behind it. (basis: derived from the deliverable of the act that files it; maintainer, 2026-10-02, for the order)
