# Traceability

One table that ties each requirement to everything that carries it, so a changed requirement shows at once what it reaches.

## Membership

Kept by document rather than produced by a step: one row per requirement in the [spec](spec.md), filled in as the plan parts, the units of work, the commits and the tests that carry it are filed, each cell linking its source. A changed requirement reopens its row: the cells it invalidates are marked, never silently kept. (basis: maintainer, 2026-09-30)
