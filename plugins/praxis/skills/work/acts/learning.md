# Learning

**Entry condition.** The request is to understand an unfamiliar part of the system and leave documentation of it: how it works, its formats and settings, how to operate it. A quick question about the code goes to [understand](../../understand/SKILL.md) directly, with no task. (basis: maintainer, 2026-09-30)

**Done when** the explored part's system documentation is filed: an explanation page, plus reference, how-to and concept pages where the results carry them. (basis: derived from the steps' outcomes)

## Steps

(basis: maintainer, 2026-09-30)

| # | step | inputs | skipped by the act when |
|---|---|---|---|
| 1 | [understand](../../understand/SKILL.md) | the part the request names, and the question about it | never |
| 2 | [gather](../../gather/SKILL.md) `--explorers=official-documentation`, adding `authoritative-literature` when step 1 names a standard | the libraries, frameworks and standards step 1's map says the part relies on | step 1's map names none |

## Filed

The results file as system documentation of the part, one content type per page: an explanation of how it works and why, a reference page for its formats, endpoints and settings, a how-to for each operation the results describe, and a concept page for each outside standard or framework mapped onto it. Step 1's map also files as a section of the task's scratchpad. (basis: maintainer, 2026-09-30)

## Delivered

Close-out's report carries the documentation's link to the user.
