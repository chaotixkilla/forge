A traced path tells you what the code does; it does not tell you why it is that way, whether it was tried differently before, or whether the record agrees with what you traced. This phase is where "this looks wrong" becomes "this was deliberately changed in review request #88 to fix X," or "the doc says X but the code does Y — a divergence."

## Delegate the corroboration to gather
Delegate this cross-lane read to gather: invoke [gather](../../gather/SKILL.md) with the framed sub-question and, **as its explicit explorer set**, the lanes this step touches — `repository` (why it is this way: prior attempts, reverts, linked discussion, anchored to commits/review requests), `knowledge-base` (recorded decisions, plans, runbooks), and `official-documentation` (the external contract, when the question touches one). Take back its weighted, anchored picture with conflicts and gaps flagged; understand owns the reconcile call, gather owns the fan-out, and its `knowledge-base` lane reads through the [knowledge](../../knowledge/SKILL.md) port, which owns the `tools.knowledge` prerequisite. **When fan-out is unavailable** — the context can't spawn the explorers gather would recruit — gather still runs, inline: it does its lanes' reads itself (the history and any docs you can reach) and still weighs and returns its picture, so the synthesis isn't skipped with the subagents; the reads are not optional, only the fan-out is.

## Reconcile the record against the behavior
gather returns claims *from the record*; hold each against what you *traced* ([follow-execution-not-names](../../../craft/evidence/follow-execution-not-names.md)). When a Tier-2 claim (a doc, a comment, a commit message) contradicts the Tier-1 behavior you traced, apply [find-the-source-of-truth](../rules/find-the-source-of-truth.md): believe the code for what the system *does*, and surface the divergence as a finding — a bug, a stale description, or an open divergence — never silently reconcile it. gather flags conflicts and project-vs-norm divergences; understand decides which are behavior findings for the map, because it holds the traced behavior gather does not.

## Anchor the "why"
Anchor each "why it's this way" claim to its evidence in history — the commit or review request, not the current file ([anchor-every-claim](../../../craft/evidence/anchor-every-claim.md)) — and grade it ([certainty-scale](../rules/certainty-scale.md)): a reason stated in a commit message is *traced* only if you read the diff it describes, *assumed-unverified* if you are taking the message's word for it. gather's lane grades land the same way: a repository finding *on-record* whose diff you read → traced; *reconstructed* → inferred; a knowledge-base finding is a document's word → assumed-unverified, its staleness grade carried beside it, and a *superseded* one is not the current why — list it as a divergence. `(basis: derived from the rungs' tests)`

The output of this phase: the behavior map enriched with why-it's-this-way, and every record-vs-code divergence surfaced as a finding — handed to [synthesize-the-answer](05-synthesize-the-answer.md).
