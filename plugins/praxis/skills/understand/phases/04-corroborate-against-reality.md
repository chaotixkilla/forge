A traced path tells you what the code does; it does not tell you why it is that way, whether it was tried differently before, or whether the record agrees with what you traced. This phase checks the behavior map against history and recorded ground truth — again by delegating the cross-lane read to gather — and reconciles what the record claims against what the code actually does. It is where "this looks wrong" becomes "this was deliberately changed in PR #88 to fix X," or "the doc says X but the code does Y — a divergence."

## Delegate the corroboration to gather
Delegate this cross-lane read to gather: invoke [gather](../../gather/SKILL.md) with the framed sub-question and, **as its explicit explorer set**, the lanes this step touches — `repository` (why it is this way: prior attempts, reverts, linked discussion, anchored to commits/PRs), `knowledge-base` (recorded decisions, plans, runbooks), and `official-documentation` (the external contract, when the question touches one). Take back its weighted, anchored picture with conflicts and gaps flagged; understand owns the reconcile call, gather owns the fan-out and its `tools.knowledge` prerequisite. **When fan-out is unavailable** — the context cannot spawn a gather subagent — do these reads inline yourself (read the history and any docs you can reach) before proceeding; the reads are not optional, only the delegation is.

## Reconcile the record against the behavior
gather returns claims *from the record*; hold each against what you *traced* ([follow-execution-not-names](../rules/follow-execution-not-names.md)). When a Tier-2 claim (a doc, a comment, a commit message) contradicts the Tier-1 behavior you traced, apply [find-the-source-of-truth](../rules/find-the-source-of-truth.md): believe the code for what the system *does*, and surface the divergence as a finding — a bug, a stale description, or an open divergence — never silently reconcile it. gather flags conflicts and project-vs-norm divergences; understand decides which are behavior findings for the map, because it holds the traced behavior gather does not.

## Anchor the "why"
Anchor each "why it's this way" claim to its evidence in history — the commit or PR, not the current file ([anchor-every-claim](../rules/anchor-every-claim.md)) — and grade it ([separate-fact-from-inference](../rules/separate-fact-from-inference.md)): a reason stated in a commit message is *traced* only if you read the diff it describes, *assumed-unverified* if you are taking the message's word for it.

The output of this phase: the behavior map enriched with why-it's-this-way, and every record-vs-code divergence surfaced as a finding — handed to [synthesize-the-answer](05-synthesize-the-answer.md).
