# Guard against confirmation

The failure mode of research is not too few sources — it is finding exactly the sources that confirm the answer you already leaned toward. Search rewards the query you write, and a query written to confirm will confirm. The discipline is to spend deliberate effort trying to *break* the emerging answer. Cited from [gather-evidence](../phases/03-gather-evidence.md) and [verify-claims](../phases/04-verify-claims.md).

1. **Query for the counter-case.** For each load-bearing claim, run the search that would surface its refutation — "X considered harmful," "why not X," the failure reports and the negative results — not just "X best practice." An answer only ever confirmed, never attacked, is not yet verified.
2. **Weight a disconfirming source at least as heavily as a confirming one.** A credible source that contradicts your answer is a finding, not noise to search past; it either corrects the answer or forces you to state the boundary where it stops holding ([surface-disagreement](surface-disagreement.md)).
3. **Beware the fluent consensus.** Broad agreement can be real corroboration or a widely-copied error; the tell is independence ([triangulate-before-trusting](triangulate-before-trusting.md)) — if the agreeing sources all trace to one origin, the consensus is one voice amplified, and the disconfirming search matters more, not less.
