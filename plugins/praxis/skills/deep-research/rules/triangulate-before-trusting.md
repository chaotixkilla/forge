# Triangulate before trusting

A single source is a hypothesis, not a fact. Promoting a claim on one source's say-so is how a research run inherits that source's error or bias wholesale; corroboration across *independent* origins is what turns a hypothesis into a finding. But only real independence counts — echoes of one origin masquerade as agreement. Cited from [verify-claims](../phases/04-verify-claims.md).

1. **Count origins, not sources.** Ten pages asserting a claim are one origin if they all trace to the same study; count distinct origins — authors and outlets not drawing on a common original — never raw citation count. Trace the echoes to their source before you count ([prefer-primary-sources](prefer-primary-sources.md)).
2. **Independence grades down when unsure.** Two origins corroborate only when neither draws on the other. When you cannot establish that a second origin is first-hand rather than an echo of one already counted, treat it as the same origin and do not let it raise confidence — an unverified second origin is not corroboration. (basis: the conservative-independence default of encyclopedic sourcing — WP:INDEPENDENT — and OSINT source grading, mirrored in gather's [corroborate-across-independent-origins](../../gather/rules/corroborate-across-independent-origins.md), which cites this rule as its basis.)
3. **Corroboration strengthens within a tier; it does not cross tiers.** Any number of independent weak sources agreeing remains weak-tier evidence, below a single strong source on the same claim — corroboration raises confidence *within* a source-strength tier, never promotes a claim across one ([weight-by-source-strength](weight-by-source-strength.md)). How corroboration count combines with source strength to lift a claim's confidence is the [claim-confidence-scale](claim-confidence-scale.md).
