# Deep mode — `--deep`

Escalate depth for a hard or high-stakes question: the same procedure, run wider and for more rounds, rather than a single pass. Activated from [plan-the-search](../phases/02-plan-the-search.md); it reshapes the dials, never the method.

What it widens:
1. **Lane set** — engage the authoritative-literature lane on *every* sub-question, not only the settled-knowledge ones, and add a second lane to any sub-question a single lane would otherwise carry alone, so no load-bearing answer rests on one source type.
2. **Fan-out and rounds** — more parallel threads per lane, and more rounds of lead-chasing before the saturation stop ([know-when-to-stop](../rules/know-when-to-stop.md)) — deep mode chases leads it would let lie in a single pass.
3. **Disconfirmation** — spend a full counter-search per load-bearing claim ([guard-against-confirmation](../rules/guard-against-confirmation.md)), not just the opportunistic one a default pass runs.

`--deep` is orthogonal to `--verify` ([verification-level](../rules/verification-level.md)): it widens *gathering*, verification rigor is set independently. It composes with `--budget`/`--timebox` — a bound still caps the wider run, which then stops early and reports itself bounded.
